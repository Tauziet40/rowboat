# rigs

Un rig OpenRig par incrément (`increment-<n>/rig.yaml`), des prompts de rôle communs dans `shared/roles/`. Rôles et règles : `knowledge/methode/deploiement-v1.md`, partie C (M5) et annexe C. Le format de `rig.yaml` est à valider contre la spécification de rig d'OpenRig (`docs/reference/rig-spec.md` du dépôt openrig).
